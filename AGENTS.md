# Contexto

App web para unir varios PDF en uno solo, de uso personal. El procesado ocurre íntegramente en el navegador: los archivos no se suben a ningún servidor. La prioridad es una interfaz agradable y clara.

# Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- pdf-lib

# Decisiones caras de cambiar

Ninguna: sin multi-tenant, sin roles ni permisos, sin offline ni sincronización, sin multi-idioma ni multi-moneda.
